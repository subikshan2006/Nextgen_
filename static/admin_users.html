🔐 Passwords are stored as bcrypt hashes — they can never be read back, not even by you. That is deliberate: it means a database leak can't reveal anyone's password. What an admin can do is set a new password for any account (use the Reset button in the table) — that's the safe, standard way to help a user who forgot theirs.
